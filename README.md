# Wild Survival 3D (වනාන්තර පැවැත්ම 3D)

A native Android 3D First-Person Forest Island Survival game built with Kotlin, Jetpack Compose, and OpenGL ES 2.0.

## Features
- **3D OpenGL ES 2.0 Island World**: Procedural ocean, grassy island, sandy beach, glowing freshwater pond, pine & oak trees, rocks, berry bushes, flickering campfires with dynamic point lighting, starfield, and day/night cycle.
- **First-Person Controls & Viewmodel**: Virtual analog joystick, touch look-drag, sprint, jump, crosshair raycast target prompts, animated 3D hand with Stone Axe, Hunting Spear, Hand Torch, Berries, and Herbal Bandage, plus hardware keyboard support.
- **Survival & Nighttime Wolves AI**: Health, hunger, thirst, and stamina decay, campfire warmth regeneration & refueling, and nighttime wolves repelled by campfires and hand torches.
- **Survival Crafting Book (නිර්මාණ පොත)**: Interactive crafting modal with category tabs (`All`, `Tools`, `Camp`, `Food`) and 6 recipes (Stone Axe, Hunting Spear, Hand Torch, Campfire, Herbal Bandage, Cooked Meat Feast).
- **Procedural Sound Synthesizer**: Native `AudioTrack` PCM synthesizer for footsteps, tool swings, tree chopping, stone mining, berry picking, drinking, crafting, wolf howls, and damage effects.
